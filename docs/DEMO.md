# Five-minute demo outline

This is a recording plan, **not a finished video**. Capture the verified system and clearly identify simulated versus actual results.

1. **0:00–0:40** — Challenge objective, four current candidate markets, account credit scope and dates.
2. **0:40–1:30** — `markets` check; show current allowlist and package exclusions.
3. **1:30–2:30** — Show a real AI shadow decision with its signals, reason and input hash. If no key is available, explain that the fail-closed response is `HOLD`.
4. **2:30–3:30** — Show an approved and a rejected simulated order, risk limits, and hash-linked audit log. Do not imply a simulated fill is an exchange fill.
5. **3:30–4:20** — Show historical results with fees, spread, return, drawdown, and limitations.
6. **4:20–5:00** — Reproduce tests, show Git commit hash and README commands, and identify the exact version running on the server. Only show live execution if credit routing has been independently verified.

Before submission, record and upload the public video, check its accessibility without login, and put the public URL in the final submission alongside the GitHub URL.
